Weekly Ranking Receipt Generator

Status: Implemented and verified

Date: 2026-05-19

Task: Build MVP /receipts/weekly page using live leaderboard data and PNG export.

Top 3 notes:

  1. The build is intentionally frontend-only; no receipt archive, cron, or server upload was added.
  2. Exact AI-agent category matching uses current leaderboard narrative fields. If fewer than five matches exist, the card visibly labels a curated fallback from current ranking rows.
  3. Rank delta uses available score-trend data because historical rank movement is not present in the existing leaderboard response.

Design Decisions

  • Added route /receipts/weekly through the existing Wouter router.
  • Used useLeaderboard instead of a new endpoint to keep MVP static/frontend-first as specified.
  • Generated a 1200x1200 receipt card for X image use, with dark cyber styling matching Nash's existing visual language.
  • Kept caption and footer language research-safe: no price targets, no trade recommendations, no performance promises.

Deviations

  • No full backend/public archive was added because the spec explicitly placed that out of scope for MVP.
  • No exact prior-week rank delta was implemented because the current frontend leaderboard data exposes score trend, not prior rank history. The card labels rows as +/- score, flat, or tracked.
  • External token images are filtered during PNG capture if CORS would taint the canvas, matching the defensive pattern used by existing share-card capture.

Tradeoffs

  • Chose current leaderboard reuse over API expansion: faster, safer, and enough for an acquisition artifact MVP.
  • Chose explicit source-mode labeling over pretending category coverage is exact when narrative metadata is incomplete.
  • Skipped adding the route to top navigation to avoid promoting an internal marketing generator as a core user feature before two polished receipts exist.

Open Questions

  • Should this become a public archive later after two polished receipts exist?
  • Should the backend store weekly rank snapshots so future cards can show true rank deltas?
  • Should a 1080x1920 story variant be added next?
